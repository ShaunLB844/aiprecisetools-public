# AIPreciseTools

Free tools for streamers, creators and everyday questions: stream overlays and alerts, OBS settings for your graphics card, a free Twitch chat bot, and calculators for money, health, home projects and school. No sign-up, and most tools run entirely in your browser.

Website: https://aiprecisetools.com

## What's here

This is the public home of AIPreciseTools. The site's source code is private. This repository is for the things people can use and ask about.

- Free overlay packs: https://aiprecisetools.com/tools/free-overlay-packs
- Overlay Suite (alerts, chat box, goals): https://aiprecisetools.com/tools/overlay-suite
- Free Twitch chat bot: https://aiprecisetools.com/tools/chat-bot
- All tools: https://aiprecisetools.com/tools/
